# The Dropped Torch

*Neurodiversity, Spirituality, and the Evolution of Consciousness*

A speculative, associative history that argues neurodivergence is the living
legacy of archaic-human hybridization — the same cognitive type that foraging
cultures institutionalized as the shamanic specialist, that empire
systematically destroyed, and that keeps re-erupting despite suppression.
